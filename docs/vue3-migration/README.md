# Vue3 业务迁移手册

> **受众**：业务开发、使用 Trae / 其他 AI / 纯手工改代码的同事。  
> **前提**：基建组已完成 Vue3 底座（见仓库 Skill `vue2-to-vue3-framework-init`）。  
> **方式**：一次改一个文件或一个业务模块即可，无需通读全文。

## 阅读顺序

| 文档 | 何时看 |
|------|--------|
| [00-别动什么.md](./00-别动什么.md) | **改任何文件前** |
| [01-改一个vue.md](./01-改一个vue.md) | 改业务 `.vue` 页面 |
| [02-改一个api.md](./02-改一个api.md) | 改或新增接口调用 |
| [03-hos-biz用法.md](./03-hos-biz用法.md) | 页面含 `el-biz-table` / 弹窗 |
| [04-多层alias速查.md](./04-多层alias速查.md) | 仅多层项目；确认 import 路径 |

## 改完自测（每个文件）

1. 对应菜单能打开
2. 浏览器控制台无红色报错
3. 点一下原功能（列表 / 保存 / 弹窗）

不要求全仓 `type-check` 通过；改一批验一批即可。

## 与基建组的分工

| 基建组（已完成或进行中） | 业务组（你们） |
|--------------------------|----------------|
| Shell、`@base` 非 views、构建、dynamic-loader | `@base/views`、子产品、`biz` 下的页面与 api |
| hos-biz **内部**实现 | hos-biz **用法**（本手册 §03） |
| Pinia / composables / 路由守卫 | 业务页改用 composables |

有问题先查 [00-别动什么.md](./00-别动什么.md)，避免改到基建文件。
