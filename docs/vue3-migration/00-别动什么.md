# 00 — 别动什么

改业务前先看。违反下列规则可能导致全站无法启动。

## 单层项目：不要改

| 路径 | 原因 |
|------|------|
| `src/main.ts`（或 `main.js`） | 入口 |
| `src/permission.ts`、`src/router/` | 路由守卫 |
| `src/axios/`、`src/stores/` | 请求与全局状态 |
| `src/components/hos-biz/**`（内部实现） | 基建维护 |
| `src/layout/` | 布局框架 |
| `src/utils/`、`src/composables/` | 除非基建组明确要求 |
| `vite.config.ts`、`env` | 构建配置 |

## 多层项目：不要改

| 路径 | 原因 |
|------|------|
| `src/main.js`、`App.vue`、`moduleConfig.js`、`dynamic-loader.js` | Shell |
| `src/load-api.js`、`load-layout.js`、`load-views.js` | 自动生成，跑 `npm run gen` |
| `src/sys/hos-app-base/` **除 `views/` 外** 全部 | 平台基建 |
| 含：`api/`、`axios/`、`router/`、`store/`、`components/`（含 hos-biz 内部）、`utils/`、`permission.js` 等根目录 `.js` | |

## 可以改（业务组负责）

| 单层 | 多层 |
|------|------|
| `src/views/**` | `src/sys/hos-app-base/views/**` |
| 项目内业务 `api`（若不在基建目录） | `src/sys/low-code/**`、`src/sys/origin-data/**`、`src/biz/**` |

## 契约不要破

- `el-biz-table` 的 `cols`、`form`、`table-data`、`uid` 语义 — 见 [03-hos-biz用法.md](./03-hos-biz用法.md)
- 不要去掉 `uid` 刷新模型
- 不要把 `el-biz-*` 换成别的表格框架（除非项目另有决定）

## 新代码规范（必须遵守）

- 不要新增 `Vue.prototype` / `globalProperties`
- 不要新增 Vuex、`mixins`（旧页面可暂留，新改动的逻辑用 composable）
- 新接口用 `fetchXxx` + `httpGet`/`httpPost`，见 [02-改一个api.md](./02-改一个api.md)
- 不要删除 `dynamic-loader` / `moduleConfig`（多层）

## 过渡期允许

- 业务 `.vue` 仍为 Options API（`export default { ... }`），能跑即可，再逐步改 `<script setup>`
- 多层项目存量 `$api('module.xxx')` 可暂时保留，新写的请用 `fetchXxx`
